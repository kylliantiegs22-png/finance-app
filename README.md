# Finance App

A free, Duolingo-style app for learning personal finance in about 10 minutes a day, with Australian examples.

- `docs/` holds the research the app is built from: curriculum, learning research, design system, engagement ideas and UX ideas.
- `GOAL_PROMPT.md` is the prompt to paste into Claude Code's `/goal` command to build the app.

General information only, not financial advice.
